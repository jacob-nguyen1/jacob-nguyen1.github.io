Projects

Bare-metal RC car

STM32F446 · C · 2026

An IR-remote car written without the HAL. Every driver (GPIO, timers, PWM, DMA, UART) comes from the reference manual. Timer input capture and DMA record the remote's pulses, and a PI loop holds wheel speed using encoder feedback.

The bug that took longest: once DMA was reading the capture register, my interrupt stopped firing, because that read clears the flag before the CPU sees it. I ended up routing the same pin into a second capture channel just for the CPU.

VGA Pong

DE10-Lite FPGA · SystemVerilog · 2026

Two-player Pong entirely in hardware, with no CPU. It generates 640×480 VGA timing from a 25 MHz pixel clock, runs the game as a state machine, and draws sprites from block RAM, with an extra pipeline stage to line up the RAM's one-cycle read delay with the pixel position.
