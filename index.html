0x02 Projects

Apr 2026 · Solo

Bare-metal RC Car

An IR-remote car on an STM32F446 with no HAL and no Arduino: every peripheral is driven by register writes I looked up in the reference manual. It started as GPIO motor toggling and grew into closed-loop speed control.

  • IR commands captured by timer + DMA, so the CPU never polls for edges.
  • PI speed control from wheel encoders, running at 100 Hz.
Hardest bug The DMA was clearing my interrupt flag before the CPU ever saw it, so the car kept timing out. The fix was a second capture channel on the same pin.

Mar 2026 · FPGA

VGA Pong

Two-player Pong in pure hardware on a DE10-Lite. There is no CPU: the game logic, the renderer, and the VGA timing are all logic I wrote in SystemVerilog.

  • 640×480 @ 60 Hz VGA from a 25 MHz pixel clock.
  • FSM-driven game states; pixel-coordinate collision across 7 concurrent inputs.
  • BRAM ROM bitmaps with pipeline registers to compensate for 1-cycle read latency.

SwampRise Bus Alarm

An alarm clock that watches live campus bus data and moves your wake-up time when the bus runs late. Won Best Integration of Hardware at SwampHacks XI.
