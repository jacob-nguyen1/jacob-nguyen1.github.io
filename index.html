Projects

Bare-metal RC car 2026

An IR-remote car on an STM32F446, written without the HAL. Every driver (GPIO, timers, PWM, DMA, UART) comes from the reference manual. Timer input capture and DMA record the remote's pulses, and a PI loop holds wheel speed using encoder feedback.

The bug that took longest: once DMA was reading the capture register, my interrupt stopped firing, because that read clears the flag before the CPU sees it. I ended up routing the same pin into a second capture channel just for the CPU.

VGA Pong 2026

Two-player Pong on a DE10-Lite FPGA, entirely in SystemVerilog with no CPU. It generates 640×480 VGA timing from a 25 MHz pixel clock, runs the game as a state machine, and draws sprites from block RAM, with an extra pipeline stage to line up the RAM's one-cycle read delay with the pixel position.

SwampRise 2026

A hackathon alarm clock that follows live campus bus data and moves your alarm if the bus is running late. It runs on an ESP32 with FreeRTOS, a DS3231 clock, an LCD, and a 7-segment display. It won Best Integration of Hardware at SwampHacks XI.
